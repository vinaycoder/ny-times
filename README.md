# Getting Started
Get clone of this Repo ( https://github.com/vinaycoder/ny-times.git )
#### install package  ( npm install )
#### if facing any legancy error Please run command ( npm install --legacy-peer-deps )
#### to start a project ( npm start )


## Available Scripts
![image](https://github.com/user-attachments/assets/8ef7c5ed-3a0b-42a8-88fc-306ae5f5ce1b)


### `npm start`
Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) 

### `npm run build`
Builds the app for production to the `build` folder

### `npm run test`
Launches the test runner in the interactive watch mode.\

### `npm run test:coverage`
to check the coverage 

### ` npm run lint `
To check the lint issue

### ` npm run lint:fix `
To fix lint issue
